Phoenix4All
-----------

Phoenix4All is fully integrated into TauREx 3. The ``phoenix4all`` star is
provided by the `phoenix4all <https://github.com/taurex-space/phoenix4all>`_
package, which is a required dependency and registers itself automatically
through the ``taurex.plugins`` entry point.
