==================
Practical Examples
==================

This section is the quickest way to get hands-on with TauREx.
Start with the library quickstart if you want to explore most of the TauREx features in a single notebook.
If you prefer a more exploratory workflow,
the notebook walkthroughs cover the same ideas in smaller, runnable steps.
Eventually, you can use the command-line quickstart if you want a guided run using the
standalone ``taurex`` program.
